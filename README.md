# ConViene — Landing page

Este repositorio contiene la landing page de **ConViene**, nuestra app para comparar precios de supermercados y planificar mejor cada compra.

En la página explicamos cómo funciona la app y mostramos una demo interactiva: podés buscar productos, armar un changuito y ver cuánto costaría la lista completa en cada supermercado. ConViene también muestra una combinación que elige el menor precio disponible para cada producto, aunque eso implique comprar en distintas tiendas.

## Sobre la demo

La demo permite conocer el recorrido principal de ConViene desde el navegador. Usa fotos de productos reales y **precios simulados**; no representa cotizaciones ni disponibilidad actuales. La app incluye más funciones que las mostradas acá, como escaneo de códigos, favoritos, medios de pago y beneficios.

Los nombres y logos de los supermercados identifican fuentes de consulta. Su presencia en esta página no implica una asociación comercial con ConViene.
